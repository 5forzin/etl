# Security

ETL is at the design stage and is not ready to protect production traffic.

Do not include credentials, private keys, personal browsing data, or unredacted packet captures in issues or pull requests.

Report vulnerabilities through GitHub's private vulnerability reporting feature when available. If it is unavailable, open an issue requesting a private contact channel without publishing exploit details or sensitive information.

Security properties and limitations are documented in [the architecture](docs/architecture.md). Claims about detectability must be supported by a stated test environment and reproducible evidence.
